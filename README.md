# Membase docs

Published with GitBook. This repository is a **mirror**: the source of truth is `docs/` in
`unibaseio/membase-suites` (`docs/user-guide` at this root, `docs/developer` under
`developer/`, one directory per tab), and `scripts/sync-user-guide.sh` there pushes every
change here. Do not edit files in this repository directly — the next sync overwrites them.
