# Keyboard shortcuts

| Where | Key | Does |
|---|---|---|
| Home box | Enter | send |
| Home box | Shift+Enter | new line |
| Home box | ↑ | recall your last question |
| Home box | Esc | stop the reply |
| anywhere on Home | ⌘⇧O | new conversation |
| Space | right-click a row | rename, move, delete, download |
