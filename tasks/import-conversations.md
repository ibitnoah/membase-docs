# Import your chats with other assistants

The Unibase Memory browser extension captures your conversations with other assistants and
hands them to a memory as a source.

1. On the memory's page, press **Install** on *Unibase Memory*. Once the extension is
   connected, the same door says **Use here**.
2. Press **Use here**. The door says *Reading* and the source appears in the Add card.
3. Press **Run**.

A memory over your conversations keeps memory about *you*: what you asked, decided, adopted. It
does not restate what an assistant explained. Its instruction is a filter on the chats: *unibase*
keeps what the chats say that bears on Unibase, not a description of Unibase.
