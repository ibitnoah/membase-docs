# Turn a project folder into a memory

You have a repo or an Obsidian vault and want your AIs to know its decisions and conventions.

1. **Memory › New memory.** Name it after the project. Under *Keeps*, pick **Decisions** or
   leave **Anything useful**.
2. On the memory's page, press **Upload** on *Upload Files* and drop the folder, or **Choose**
   on *Your Space* if the files are already there. Markdown, text and common document formats
   are accepted; the dialog tells you before sending if a file is not.
3. Press **Run**. Wait for *Updated just now · Report*.
4. Open **Report** to see what it read and what it kept.

Whenever the files change, the button says **Update now**. Press it, or
[put the memory on a schedule](schedule-updates.md).
