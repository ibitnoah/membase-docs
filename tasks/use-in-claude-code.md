# Use a memory in Claude Code

1. **Connect › Claude Code.** The connector URL and the steps for Claude Code unfold.
2. Run the command shown in a terminal. Claude Code opens the browser sign-in.
3. Approve access in Membase and tick the memories Claude Code may read.
4. In Claude Code, ask about your project. It reaches for your memory on its own when the
   question needs it.

To stop: **Connect › Claude Code › Disconnect…**, or turn one memory's switch off under
**Uses**. Either takes effect on the next question.
